# 한자 탐험대

아이들이 태블릿에서 한자능력검정시험(한국어문회) 8급·7급Ⅱ·7급을 익히는 웹 게임.

- 한자 카드, 몬스터 퀴즈, 짝 맞추기, 따라 쓰기, 모의시험
- 한자 모험: 몬스터를 물리치고 한자 마왕까지 가는 RPG
- 탐험 지도: 포켓몬처럼 걸어 다니며 풀숲에서 한자몬을 만나요(십자키·화면 끌기·화살표). 영역 사이 바위 문은 보스를 이기면 열리고, 상점·한자 박사의 집·하루 한 번 🎁가 지도 위에 있어요. 자주 틀리는 한자가 더 자주 나오고 난이도(쉬움·보통·어려움)를 고를 수 있어요
- 한자몬: 한자볼(한자볼·슈퍼볼·마스터볼)로 잡고, 도감에서 이야기와 진화를 봐요. 깊은 숲에는 지도에 없는 한자몬이 살아요
- 상점: 모은 별로 한자볼·싸움 도구·장비 상자·오늘의 장비(하루마다 4개)·진화의 돌을 사요 (계급은 지금까지 모은 별로 정해져서, 써도 내려가지 않아요). 보물 상자는 눌러서 직접 열어요
- 파티: 잡은 한자몬을 3마리까지 데리고 다녀요. 번갈아 공격하고 싸울수록 레벨이 올라요. 도감에서 별명도 지어요
- 트레이너·체육관: 지도의 트레이너와 눈이 마주치면 한자 승부(한자몬 1~3마리 연속). 영역마다 체육관이 있어 시험(10문제 중 8개)에 붙으면 관장과 승부하고 배지를 받아요. 🪪 트레이너 카드에 배지·전적이 쌓여요
- 지도 생활: 쉼터 아저씨(하루 물약 1개)·한자 할머니(하루 퀴즈 ⭐)·낮과 밤(밤엔 한자몬이 더 자주)·신발을 신으면 👟 달리기·1/40 확률의 ✨ 반짝 한자몬
- 두더지 잡기·한자 빙고: 훈음을 듣고 한자를 찾는 빠른 놀이. 틀린 한자는 기록에 남아 다음 공부에 먼저 나와요
- 규칙: 오늘의 공부를 끝내야 모험·사냥을 할 수 있어요(부모님 화면에서 끌 수 있음). 난이도는 모은 별로 열려요(보통 120·어려움 350). 땅마다 알맞은 장비 점수가 있어 장비가 모자라면 공격이 덜 먹히고 더 아파요

## 고치는 방법
1. `src/template.html` 수정 (한자 데이터·게임 코드)
2. 대사가 바뀌었으면 `python tools/make_voice.py` (voice/*.json 생성)
3. `python build.py` → `index.html`

## 사용한 자료
- 획순: [hanzi-writer](https://hanziwriter.org) / hanzi-writer-data
- 효과음: [Kenney](https://kenney.nl) RPG Audio, Impact Sounds (CC0)
- 목소리: Microsoft Edge 뉴럴 음성(ko-KR-SunHiNeural)으로 생성
